# eligible-jobs

General session rules live in `~/.claude/CLAUDE.md` (loaded in every repo). This file holds only the rules for this repository.

- **This repository is public.** Never commit personal data: CV, profile, preferences, rates, email addresses, or anything copied from the owner's job search notes. Real values go in `.env`, `.dev.vars` or the database. Example files use fake data only.
- **Emre writes the code; Claude reviews and teaches.** Do not write feature code unless asked for that specific piece. Code written by Claude does not count as evidence of Emre's skills in an interview.
- Decisions (scope, sources, infrastructure, module order) are recorded outside this repo, in the AI Engineer Roadmap. The README summarises them; change the README only when a decision changes.
- Follow the source and content rules in the README: official endpoints only, polite scanning, no republished posting text.
